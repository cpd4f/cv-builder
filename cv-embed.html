This embed is now non-iframe: it renders directly in the page, is responsive, and is isolated from host-site CSS using Shadow DOM.

Copy/paste snippet

<div id="cv-embed-target"></div>
<script
  src="https://cpd4f.github.io/cv-builder/cv-embed.js"
  data-cv="coleman-davis"
  data-target="cv-embed-target"
></script>

Options

  • data-cv (required): CV slug, e.g. coleman-davis.
  • data-target (optional): container element id where the embed should render.
  • data-base-url (optional): override base URL if you self-host files.
