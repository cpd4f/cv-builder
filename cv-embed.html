Embed this CV on any external site

Use the script below to embed the full CV viewer layout for coleman-davis. You can change data-cv to any available slug.

Copy/paste snippet

<div id="cv-embed-target"></div>
<script
  src="https://cpd4f.github.io/cv-builder/cv-embed.js"
  data-cv="coleman-davis"
  data-target="cv-embed-target"
  data-height="1800"
></script>

Options

  • data-cv (required): CV slug, e.g. coleman-davis.
  • data-target (optional): container element id to place the iframe into.
  • data-height (optional): iframe height (pixels like 1800 or CSS value like 120vh).
  • data-base-url (optional): override the base URL if you self-host these files.
